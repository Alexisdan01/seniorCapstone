# Scholarly Pulse

Scholarly Pulse is a full-stack academic community platform developed as
my senior capstone project at the University of Wisconsin–Milwaukee.

The application was designed to provide students with course-based
discussion spaces where they can join class communities, create posts,
comment on discussions, and interact through a personalized dashboard.

## Technologies

- PHP
- MySQL
- PDO
- JavaScript
- HTML
- Tailwind CSS

## Key Features

- User registration and authentication
- Course-based discussion forums
- Join and leave class communities
- Create, edit, and delete posts
- Comment on discussions
- Post likes and engagement tracking
- Personalized student dashboard
- Trending discussion calculations
- Administrator-controlled forum creation
- Role- and ownership-based permissions

## Security & Backend Design

- PDO prepared statements
- Server-side authorization checks
- Password hashing using PHP `password_hash()`
- Session ID regeneration on login
- Database credentials separated from source code
- HTML output escaping to reduce XSS risk
- Database transactions for multi-step operations

## Academic Project Disclaimer

Scholarly Pulse was developed as a student senior capstone project.
It is not an official University of Wisconsin–Milwaukee service.
